Taux BdC — Banque du Canada / Bank of Canada
============================================

FRANÇAIS
--------
1. Décompressez ce dossier.
2. Double-cliquez sur « Taux-BdC.exe ».
3. Si SmartScreen : Informations complémentaires → Exécuter quand même.

Dans l'application :
- Onglet Conversion : une écriture (copier / exporter CSV ou Excel)
- Onglet Lot : importer un CSV/Excel, traiter, exporter le résultat
- Modèle de colonnes : date, devise, montant, reference
  (fichier modele_lot.csv inclus)

Aucun Python à installer. Internet requis (API Valet).

ENGLISH
-------
1. Unzip this folder.
2. Double-click « Taux-BdC.exe ».
3. If SmartScreen: More info → Run anyway.

In the app:
- Convert tab: single entry (copy / export CSV or Excel)
- Batch tab: import CSV/Excel, process, export results
- Column template: date, devise, montant, reference
  (modele_lot.csv included)

No Python required. Internet required (Valet API).

Source: Bank of Canada Valet API — rates are indicative only.
