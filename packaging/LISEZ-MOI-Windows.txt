Taux BdC — Banque du Canada / Bank of Canada
============================================

FRANÇAIS
--------
1. Décompressez ce dossier.
2. Double-cliquez sur « Taux-BdC.exe ».
3. Si SmartScreen : Informations complémentaires → Exécuter quand même.

Dans l'application (mêmes fonctions que la version Mac) :

  Conversion
  - Taux du jour, moyenne mensuelle ou annuelle
  - Sens devise → CAD ou CAD → devise
  - Copier (fiche complète, montant seul, ligne Excel)
  - Week-end / férié → dernier jour ouvré BdC automatiquement

  Lots
  - Importer CSV, Excel, JSON ou XML (glisser-déposer possible)
  - Traiter → exporter CSV, JSON ou XML
  - Colonnes : date, devise, montant, reference (voir modele_lot.csv)

  Historique
  - Journal d'audit de toutes les conversions
  - Recherche, export, ouvrir le dossier data
  - Effacer l'historique (sauvegarde auto dans data/sauvegardes/)

  CLI Flash (optionnel)
  - taux.bat 2026-07-05 usd 1500 FAC-10443

Fichiers locaux :
  data/cache_taux.json              — cache des taux (hors ligne)
  data/historique_conversions.log   — piste d'audit pour les vérificateurs

Aucun Python à installer. Internet requis (API Valet).

ENGLISH
-------
1. Unzip this folder.
2. Double-click « Taux-BdC.exe ».
3. If SmartScreen: More info → Run anyway.

In the app (same features as the Mac version):

  Convert
  - Daily, monthly or annual average rate
  - Foreign → CAD or CAD → foreign
  - Copy (full summary, amount only, Excel row)
  - Weekend/holiday → previous BoC business day automatically

  Batches
  - Import CSV, Excel, JSON or XML (drag & drop supported)
  - Process → export CSV, JSON or XML
  - Columns: date, devise, montant, reference (see modele_lot.csv)

  History
  - Audit log of all conversions
  - Search, export, open data folder
  - Clear history (auto-backup to data/sauvegardes/)

  Flash CLI (optional)
  - taux.bat 2026-07-05 usd 1500 INV-10443

Local files:
  data/cache_taux.json              — rate cache (offline)
  data/historique_conversions.log   — audit trail for reviewers

No Python required. Internet required (Valet API).

Source: Bank of Canada Valet API — rates are indicative only.
