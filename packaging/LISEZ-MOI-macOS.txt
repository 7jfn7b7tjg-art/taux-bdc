Taux BdC — Banque du Canada / Bank of Canada
============================================

FRANÇAIS
--------
1. Décompressez ce dossier.
2. Double-cliquez sur « Taux BdC.app » (aucune fenêtre Terminal).
3. Si macOS bloque : clic droit → Ouvrir → Ouvrir.

Dans l'application :
- Onglet Conversion : une écriture (copier / exporter CSV ou Excel)
- Onglet Lot : importer un CSV/Excel, traiter, exporter le résultat
- Modèle : date, devise, montant, reference (modele_lot.csv)

ENGLISH
-------
1. Unzip this folder.
2. Double-click « Taux BdC.app » (no Terminal window).
3. If macOS blocks: right-click → Open → Open.

In the app:
- Convert tab: single entry
- Batch tab: import CSV/Excel, process, export
- Template columns: date, devise, montant, reference

Source: Bank of Canada Valet API — rates are indicative only.
